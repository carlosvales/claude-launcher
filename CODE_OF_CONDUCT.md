# Code of Conduct

## Our pledge

We want Claude Launcher to be a welcoming, friendly, and productive project for contributors of every background and skill level. By participating, you agree to keep interactions respectful and constructive.

## Expected behavior

- Be kind and professional in issues, pull requests, and discussions
- Critique ideas, not people
- Accept that other contributors may have different priorities, time zones, or experience levels
- Assume good intent; ask questions before jumping to conclusions
- Give credit where due

## Unacceptable behavior

- Personal attacks or insults
- Discrimination based on background, identity, or beliefs
- Sustained disruption of discussions or PRs
- Sharing other people's private information without permission
- Any conduct that a reasonable person would find inappropriate in a professional setting

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please open a private report by emailing the maintainer (see GitHub profile) or use GitHub's built-in reporting tools.

All reports will be reviewed promptly and confidentially.

## Enforcement

Maintainers may take any action they consider appropriate in response to violations, including:

- A private warning
- A public clarification
- Temporary or permanent ban from the project's spaces (issues, PRs, discussions)

## Scope

This Code of Conduct applies to all project spaces — GitHub issues and pull requests, discussions, and any communication channels associated with this repository — and to behavior outside these spaces when it directly affects the project or its community.
